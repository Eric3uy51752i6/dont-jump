NOPE?

This page describes the current browser version of DON’T JUMP. A future native iOS release may use different services and will have its own updated disclosures.

Local game data

The browser game uses local browser storage to remember settings, unlocked levels, deaths, times, selected Blobs, daily results, and created levels. That data normally stays on your device in your browser.

Clearing or moving progress

Clearing site data, using private browsing, or changing devices or browsers may reset progress. The current web build does not claim to sync progress to an account.

Rewarded-ad preview

The web version currently presents a simulated rewarded-ad flow for gameplay testing. It does not falsely claim to run native Google AdMob inside the standalone browser version.

Future iOS app

The planned native iOS app may use platform services or advertising that are not part of this web version. Those practices must be disclosed in the iOS app’s production privacy policy before release.

Technical hosting

This site is hosted with GitHub Pages. Like most web hosts, the hosting provider may process ordinary connection information needed to deliver the site. See GitHub’s own privacy materials for its practices.
