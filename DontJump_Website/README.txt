DON’T JUMP WEBSITE

Files:
- index.html       Home / marketing landing page
- support.html     App Store Support URL
- privacy.html     Privacy Policy URL
- styles.css       Site styling
- site.js          Small site helper
- site-config.js   Change support email here
- assets/          App icon

BEFORE PUBLISHING
1. Open site-config.js.
2. Replace:
   REPLACE-WITH-YOUR-SUPPORT-EMAIL@example.com
   with your real support email address.
3. Review privacy.html after the final ad/analytics SDKs are chosen.
4. Upload the entire folder to a static host.

Suggested URLs once hosted:
https://YOUR-DOMAIN.com/
https://YOUR-DOMAIN.com/support.html
https://YOUR-DOMAIN.com/privacy.html

The support.html URL can be used as the App Store Support URL.
The privacy.html URL can be used as the App Store Privacy Policy URL.

Easy hosting choices:
- GitHub Pages
- Cloudflare Pages
- Netlify

No server or database is required for this site.
